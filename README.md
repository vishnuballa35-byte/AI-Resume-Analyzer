### AI Resume Analyzer
**Technologies:** Python, FastAPI, scikit-learn, PyMuPDF, HTML, CSS, JavaScript

- Developed a web application that compares PDF resumes with job descriptions.
- Implemented TF-IDF vectorization and cosine similarity to calculate a resume–job description match score.
- Built a FastAPI backend and deployed the frontend and backend using Netlify and Render.
